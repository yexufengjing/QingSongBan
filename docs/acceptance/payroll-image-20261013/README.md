# 工资图片导出验收记录

## 实现范围

- 工资导出页保留 Excel 下载，“在应用内查看表格”打开完整图片预览。
- 按当前工资批次导出全部有效人员，保留原有 11 列、备注和合计。列表分组筛选不会缩小导出范围。
- 支持双指放大、拖动核对和保存原始 PNG 到相册。图片以 3 倍尺寸绘制，文字按实际内容换行，实发工资和合计突出显示。
- 图片与 Excel 使用同一不可变导出快照；出勤保留 1 位小数、金额保留 2 位小数。合计沿用原有批次保存值，不改变工资计算规则。
- 考勤和工资共用图片预览及相册保存组件。

## 自动检查

- 工资图片 4 项测试通过：20 人及 11 列快照与 Excel 逐格一致、完整 PNG 和长文本布局、窄屏预览与保存原图、空批次提示。
- 现有 Excel 导出 1 项、工资计算 2 项、考勤图片 6 项测试通过。
- 工资导出路由在 426.67dp、360dp 和 320dp/1.3 倍字号下共 3 项检查通过。
- 本次涉及的 11 个源码与测试文件定向分析无问题；Android debug APK 构建通过。

## Android 模拟器验证

Android API 35 的现有 2026 年 9 月工资批次包含 2 人。图片成功保存到 `Pictures/轻松办/`，系统相册可以打开并放大查看；MediaStore 记录为 `image/png`、3960 × 1113、`is_pending=0`。

实发工资为 997.50 和 1527.50，合计 2525.00，与设备实际导出的 Excel 一致。姓名、工号、工种、全部数值及换行备注均可见。

# 智能助手回复卡片可读性改版

日期：2026-10-22。按用户要求应用 taste 与 ui-ux-pro-max 的相关设计方法，直接设计、实现并在模拟器检查。

## 设计与实现

保留现有 Flutter Material 3、蓝白主题和 16dp 回复卡片圆角。设计参数为变化 3、动效 2、密度 5；不添加与业务阅读无关的装饰或动画。

改版前：回复正文将金额、人数、统计规则及工资校验事项串在同一段，字号和权重相近；多个蓝色来源按钮并列，用户需逐句找结论。

改版后按以下顺序阅读：

1. 业务标题、月份、人员/车辆范围及结果状态。
2. 大号主指标与带单位的辅助指标。金额来自本地读取结果，不从自然语言回复中提取。
3. 工资待核对事项独立为带图标和文字状态的提示区，逐条展示原校验信息，并在提示旁提供对应来源。
4. 业务记录以字段名称和对应值分行呈现；重复指向同一工资页面的提示来源与主来源合并为一个入口。
5. 计算说明、统计口径、查询时间与关联依据可展开；刷新、解释、月份追问继续可用。较长的新回复定位到卡片顶部，先展示结论。

没有匹配工资明细时，主信息显示“暂无明细”和匹配人数，不将空记录的合计零元作为实际工资展示；原始查询合计仍保留在说明中。未修改工资计算、校验规则、数据记录或来源路由。

业务指标覆盖工资、库存、采购、福利及月度车辆维修，考勤采用独立字段展示出勤、请假休息及加班。已存在的车辆专项分析与排名交互保留。

技能检索中确认采用字体层级、LayoutBuilder 自适应、平台语义控件等适用建议。针对渐进披露的检索未找到可直接用于此原生组件的匹配项，因此折叠说明采用通用的信息优先级设计判断，未把无关网页建议作为组件规范。

- 本地数据库测试核对指标对应实际查询合计、人数、原校验事项及空明细状态，读取前后数据库快照一致。

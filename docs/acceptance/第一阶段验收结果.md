## 已知边界

- `employment_records` 历史变动表尚未纳入当前 schema，人员当前状态仍由人员档案和离职记录维护。
- 固定业务提醒已提供开关与提前天数配置；需要明确业务日期的停保和自定义提醒会进行 Android 本地调度，证件到期提醒待附件/证件字段接入后补充具体日期来源。
- 恢复操作完成后需要重启应用；重启时由 Drift 执行数据库打开校验。

## 本次 UI 与附件增量

- 当前 schema 已升级到 9，新增 `employee_attachments` 和临时工工资相关表。
- 人员详情、离职登记和保险变更均可接入附件，备份包包含数据库、配置和附件文件。
- 月度汇总已提供当前月份直接导出 Excel 的入口。
- 临时工工资支持按月生成名单、日薪快照、工资确认/锁定、历史查询和 Excel 导出。
- 临时工工资首页与造资页支持考勤组筛选，工资明细显示参保状态且不自动推导保险扣款。
- 工种设置支持启用停用切换；修改工种和添加生效日薪弹窗统一布局，生效月份支持年份与月份快捷选择。

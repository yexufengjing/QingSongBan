# 智能助手：深度思考、联网搜索与峰谷提醒

状态：已完成实现、模拟器验证和普通调试版安装（2026-10-23）。

## 功能入口

- 自由对话输入框上方：深度思考、联网搜索开关，设置保存在本机，默认关闭。
- AI 设置 → 对话偏好：深度思考开关与轻度/深入/最深入强度，联网搜索开关。深度思考内容作为独立折叠区显示，输出用量包含思考消耗。
- 联网搜索使用官方 Search API 检索本轮问题前 128 个 Unicode 字符，最多 5 个来源，每个来源最多取 2000 字符作为参考；网页材料仅加入本轮，来源单独保存并可打开链接。空结果有明确提示，失败不冒充已联网。
- 助手标题旁显示峰时/谷时。橙色峰时、绿色谷时，点击查看具体价格、北京时间规则和官方文档。分钟边界及回到前台时刷新，不请求模型。

## 计费与适用范围

仅对官方 HTTPS `api.deepseek.com` 和 `deepseek-flash` 应用 Flash 峰谷价格；自定义服务或其他模型显示价格未知，不套用官方价格。`deepseek-flash` 当前对应 DeepSeek-V4.1-Flash-1017。

北京时间周一至周五 09:00–12:00、14:00–18:00 为峰时，周末和中国公众假期全天谷时，调休周末仍谷。其他时间谷。谷价为峰价的一半。美元/百万 token：

| 用量 | 峰 | 谷 |
| --- | ---: | ---: |
| 输入缓存命中 | 0.006 | 0.003 |
| 输入缓存未命中 | 0.30 | 0.15 |
| 输出 | 1.20 | 0.60 |

节假日日历已核实到 2026 年。其他年份潜在工作日峰时显示未知，避免推测假期。价格和日历核验于 2026-10-23。

联网搜索目前仅对官方 Flash/Pro 开放，第三方 Key 不会转发到官方搜索接口。搜索采用独立接口，2026-11-01 北京时间开始按每千次成功且有结果请求 $0.75 计费；聊天 token 另算。业务记录不自动附加到聊天或搜索。

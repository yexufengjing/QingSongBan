## 不明确处与默认处理

- 07–14 损坏参考图无法支持逐像素验收；依据同项目可读图及规范推导，原图保留待替换。
- 参考人员保险区有“保险单位”，现有模型无该字段：不编造单位、不为视觉调整新增数据库结构；真实已参保状态与历史变更仍按现有数据展示。
- 日考勤已有修改即保存的业务流程，参考图显示独立“保存考勤”：保留真实自动保存与状态反馈，不制造无效保存操作。
- 物资模型没有照片，使用库存图标占位；真实名称、分类、规格、单位和数量继续显示。
- 器械新增记录参考中的示例小计与明细乘积之和不一致：按真实金额计算，不复制错误示例总价。
- 车辆模型使用已有静态多视角资源与真实部件状态，参考效果不作为新增 3D 模型或虚构检查记录的依据。

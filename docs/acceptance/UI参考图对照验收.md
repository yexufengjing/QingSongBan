## 不明确处与默认处理

参考姓名、日期、数量、金额均由真实数据替代。保险模型无“保险单位”或合同/保险到期字段，不新增 schema；首页到期卡显示未来30天提醒“项”，不冒充合同人数。物资无照片时使用现有库存图标。日考勤保留真实自动保存；不制造参考中的无效独立保存按钮。车辆保留静态多视角与实际部件状态，“未记录”不改成“不适用”；无检查批次契约，不加虚假的“完成本次检查”。器械样例小计与算术不符时仍按真实数量、单价与比例计算。

本轮主审批准的是上述修正、行为回归、构建安装和明确范围内的视觉结果；没有未处理的已确认代码退回项。损坏参考和缺真实数据造成的证据缺口继续保留，不自动提交或上传。

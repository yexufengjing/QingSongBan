# 轻松办 · 全量 UI 生图提示词与生成顺序

> 用途：基于《轻松办 · 全量 UI 重构设计规范》1.0，作为 UI 预览图生成的统一执行文档。  
> 使用方式：先使用“统一母 Prompt”，再追加对应页面的“页面子 Prompt”。每次只生成一张图，确认通过后再生成下一张。  
> 基准画布：Android 竖屏，390×844 logical dp；必要时再补 360dp 适配图。  
> 视觉基线：SaaS 简约工作台、蓝灰白、冷灰页面底、白色卡片、单一蓝色强调、轻分隔、小圆角、适中信息密度。

# 七、统一验收要求

- 页面必须完整，不裁切顶栏、正文或底部操作区。
- 390×844dp 为主基准。
- 根页面显示：首页 / 考勤 / 汇总 / 我的。
- 子页隐藏主导航。
- 所有可点击目标 ≥48×48dp。
- 主按钮 48dp；长表单提交 52dp。
- 页面顶栏 56dp。
- 标准卡片 r12。
- 输入框 r8。
- 弹层 r16。
- 页面左右边距优先 16dp。
- 模块间距优先 24dp。
- 列表间距优先 8dp。
- 正文不得为了塞内容缩成 10–11sp。
- 不允许玻璃拟态、霓虹、彩虹卡片、重阴影。
- 不允许假数据图表或虚构百分比。
- 不允许删减真实业务字段。
- 不允许一个页面出现多个竞争性的主按钮。
- 危险操作必须进入更多菜单或确认层。
- 页面有数据、空、加载、错误、禁用／只读等状态必须彼此区分。

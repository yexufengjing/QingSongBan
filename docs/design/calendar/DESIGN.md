# 日历视图视觉规范

适用：轻松办新增日历、待办及日记录页面。与 `../全量UI重构设计规范.md` 和现有 `AppColors` 一致；不修改其他模块的主题。本规范将 ui-ux-pro-max 的可达性建议与 taste-design 的视觉约束用于现有 Flutter 产品，网页营销页的 Hero、外部字体和持续动画不适用于此页。

## 1. 气质

克制、易扫描、适中密度。variance 2、motion 2、density 5。日历是日期索引，下方列表承载完整信息。以清晰日期、可读正文和稳定动作形成层级，不用装饰插画、摄影横幅或虚构指标。

## 2. 颜色与角色

| Token | 值 | 用途 |
|---|---|---|
| primary | #2563EB | 选中日期、主要按钮、未完成标记 |
| ink | #0F172A | 日期与正文 |
| muted | #64748B | 时间、说明及记录标记 |
| background | #F1F8FE | 页面背景 |
| surface | #FFFFFF | 月历和内容表面 |
| divider | #E2E8F0 | 内容分隔 |
| success | #15803D | 完成反馈，同时带勾与文字 |
| danger | #B91C1C | 错误与危险操作，同时带文字 |

现有品牌蓝优先，不采用检索结果的青绿／橙色配色。语义色不是新增装饰色。深色主题应映射语义 token 并独立验证，本轮原型交付浅色方案。

## 3. 字体、间距与组件

中文系统字体，与现有应用一致；标题20sp／600，正文16sp，辅助14sp。数字对齐但不为数字引入单独的网络字体。间距8／16／24dp；页面边距16dp，卡片圆角12dp、输入8dp、弹层16dp。标题随系统字号放大，正文允许自然换行。

列表优先用分隔和留白，卡片只表达分组。所有表单有可见标签，错误出现在字段附近。按钮和复选框整项触区高48dp；7列日期格在窄屏宽度不足时不扩展重叠命中区，正式实现需提供等价日期选择路径。今日描边、选中实底、待办圆点、日记录短线、全部完成勾；同时提供图例和读屏完整描述。

## 4. 布局与响应

手机单列，月历与当日详情顺序清楚；无横向溢出，无嵌套小滚动窗。大屏可并排但保持视觉与读屏顺序。新增只有一个主要入口；展开、编辑、更多是次要操作。键盘弹出时弹层可滚动，保存与取消仍能到达；兼容底部安全区。

## 5. 状态与动效

默认、按下、聚焦、选中、提交中、成功、失败分别定义。操作结果依赖真实保存结果；失败保留输入并显示重试路径。选中与展开可使用短时透明度过渡，减少动态效果时关闭；原型不需要持续动画。键盘焦点可见，弹层焦点限制在内部，关闭后恢复到有效控件。

## 6. 禁止项

不使用霓虹、重阴影、渐变标题、彩虹日期格、卡片套卡片、文字覆盖、不必要的大图、emoji 图标或虚构完成率。不只靠颜色传达状态，不只靠手势提供删除或切月，不把未保存数据显示成已保存。

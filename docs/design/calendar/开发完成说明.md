# 日历与记录 · 开发完成说明

本轮将设计接入现有 Flutter 应用；使用两个 GPT-6-luna 高推理代码子代理，主 Agent 约束接口、审查并统一串行验证。未提交或推送 Git。

## 使用入口与已实现功能

- 首页「处理」→「待办事项」展开→「日历与记录」。
- 「我的」→「备忘提醒」右上角日历按钮；两处打开 `/settings/reminders/calendar`，子页隐藏主导航，返回保留来源页面。
- 月历周一开始，按月自然排4–6周；支持相邻月日期选择、左右滑动／箭头切月、日期选择器跳转和回到今天。切月保留日，不足取月末。
- 今天描边、选中蓝底，未完成圆点、全部完成勾、日记录短线；详情显示当日完整日期和星期、未完成与已完成分组、多条日记录。
- 待办新增、编辑、改期、删除、完成与恢复；日记录新增、修改、改日期、展开与删除。未保存退出确认，空内容校验，保存失败保留输入并显示错误，提交时防止重复保存。
- 重复事项完成只影响所点实例，支持明确跳过本次或删除整个系列；编辑前提示系列影响，再进入现有完整提醒编辑页。不会把历史未完成自动搬到今天。
- 新建待办默认不启用通知，日期和时间表达计划；需要通知可在备忘提醒完整编辑中设置。旧时间型事项保留原通知设置，改为全天时关闭旧通知，避免通知被移到午夜。保存成功后通知同步失败会单独提示，不谎报数据库保存失败。

## 数据与兼容

数据库 schema 23→24，新增 `DailyEntries`，按日期键保存独立日记录，带创建／更新时间和软删除；新增 `Reminders.isAllDay`，旧数据默认 false，保留原时刻和状态。日记录不改动考勤、工资或业务日志。

日历复用现有 Reminders／ReminderOccurrences；按可见自然周范围补齐重复实例，保留已完成／已跳过状态。查询排除已知系统提醒设置，保留车辆保养、离职保险等业务提醒。摘要和详情从同一事务快照产生，并观察实例、提醒及日记录的变动。

修复 `findItemById` 读取重复事项时对多实例使用 `.single` 的问题。单次快捷编辑保留关联对象、分类等元数据，以及已经完成的状态。现有整库备份自动包含新表与全天字段，无需增加第二套备份机制。

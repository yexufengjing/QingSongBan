### 0.8 本稿的整体共同理解

全量重建轻松办UI，浅色、安卓竖屏优先，蓝灰白SaaS简约、适中信息密度；管理人员与负责人并重，入口／布局／字段顺序／组件可重组，业务能力和原有规则保留。首页／考勤／汇总／我的四主导航；首页概览八指标固定今天／本月／上月，处理集中业务，低频工具在我的原位折叠展开。车辆档案列表为主体，详情七项横滑且当前车提醒与全车提醒分开；费用数字明细优先、环形／折线图折叠。库存领取是实际领取后的记录，日期摘要列表、多项明细、共用时间／领取人；日考勤单人半日编辑并自动保存，月表锁姓名和表头。子页隐藏主导航，当前有效主动作固定底部。品牌有序办理几何＋字标，静态启动就绪直接进入。

## 2. 风格规范

**结论：**采用SaaS简约工作台，整体视觉重建。**依据：**用户明确偏好SaaS简约；App含大量中文台账、日期、金额和数量操作，需要稳定扫描和克制的视觉强调。**范围：**全局浅色主题及所有模块。**执行标准：**以下风格约束用于每张后续设计图。

| 关键词 | 气质及可执行规则 | 不采用的方向 |
|---|---|---|
| 清晰 | 一屏一个主任务；字段label常驻；业务名称直接；数据单位不省略 | 大图遮字段、纯图标入口、营销式文案 |
| 克制 | 白／冷灰为底，单一蓝色为主要交互；大片彩底仅预警、摘要、空态 | 玻璃拟态、霓虹紫蓝、彩虹模块卡片、重阴影 |
| 稳定 | 卡片12、控件8、弹层16统一圆角；位置保持一致 | 每模块独立圆角／字号；跳动数字、自动轮播 |
| 高效 | 主要内容14–16sp；可点区≥48dp；重复列表紧凑，必要详情可展开 | 把密度提高等同于把字缩至10–11sp |
| 功能性视觉 | 首页用文字标题、范围与数据建立识别；真实车辆图仅作车型／部件定位；附件显示真实内容 | 首页摄影横幅、装饰性现场人物插画、大面积渐变、虚构头像 |

taste参数建议：`DESIGN_VARIANCE=2`、`MOTION_INTENSITY=2`、`VISUAL_DENSITY=5`（审美判断，非测量数据；密度按用户已选“适中”落实）。现状推断约4/2/6，各模块差异明显。统一图标使用现有 Material outlined 家族；主导航选中可用对应filled图标。图标24dp、业务入口32dp、空态48dp，不混多套线宽风格。首页移除装饰摄影横幅，采用56dp标题与日期／范围区；已确认保留“轻松办”名称，重建App图标、Logo和启动画面；已确认规整线块＋简洁勾形转折表达有序办理；具体Logo图稿后续制作，启动采用静态简洁画面，就绪直接进入，本轮只更新规范。


**品牌资产拟定制作标准：**符号由2–3条规整线／块与简洁勾形转折构成，不绘成真实待办复选框、绿色成功状态或任一业务专属图标。主版蓝色＋字标，单色版和反白版同时交付SVG及所需PNG；16、24、48dp检测转折与留白，最小显示尺寸16dp，内部间隙目标≥2dp。符号到字标间距8dp，独立Logo四周留白至少符号高度的1/4；最终以方案图辨识结果校准。Android adaptive icon分别交付前景、背景与单色图层，108dp基准画布、关键符号按48–66dp尺寸控制在中央安全范围；不得把整段字标塞入小图标。图标蒙版和系统启动画面按目标Android版本验证。图标图层尺寸依据[Android adaptive icon规范](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive?hl=en)。名称与几何意象已确认，具体图形、矢量路径、原生资源均属于后续制作。


**启动合同（Q46已确认，平台尺寸为实现标准）：**静态浅色品牌画面，就绪直接进入，不额外停留。Android 12+原生启动屏使用单色不透明背景和系统中央图标槽，不把普通页面“符号＋字标”组合强塞进图标资源；字标若需要显示可用平台支持的底部branding区域（200×80dp），或留在进入后的首页标题。官方建议克制使用branding图，不额外增加一张必须停留的品牌页面。有图标背景时资源240×240dp、有效内容落在160dp直径圆内；无背景时288×288dp、有效内容落在192dp直径圆内。它与108dp的launcher icon交付不是同一尺寸；具体平台资源按[Android SplashScreen规范](https://developer.android.com/develop/ui/views/launch/splash-screen)导出。业务数据加载用首页对应骨架，不为等待数据重复播放启动动画。

仅动机明确的过渡：按钮120ms、选中160ms、展开200ms、页面进入200–240ms；禁止永动悬浮／数字滚动／反复闪烁。系统减少动态效果时变为即时切换或淡入≤100ms。已确认先完整设计浅色全量页面，深色后续另做，不以自动反色替代深色设计。

### 3.2 对比度校验与禁用组合

本轮按sRGB相对亮度公式计算以下纯色组合；结果展示四舍五入，验收使用未舍入值。正常大小文字统一采用≥4.5:1，必要图标／状态边界≥3:1。阈值依据[Flutter UI可访问性](https://docs.flutter.dev/ui/accessibility/ui-design-and-styling)、[W3C文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)与[非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。本项目对大标题也优先≥4.5:1，避免移动sp与Web pt换算引起误用。

| 前景／背景 | 对比度 | 结论 |
|---|---:|---|
| 白／`#00C16B` | 2.37:1 | 禁止白字主按钮、小标签；亮绿不是可读按钮底 |
| `#94A3B8`／白 | 2.56:1 | 禁止辅助信息、占位和必要图标用旧helper |
| 白／`#1677FF` | 4.10:1 | 不作为常规小字按钮组合 |
| 白／`#E05252` | 3.82:1 | 不作常规危险按钮组合 |
| 白／`#2563EB` | 5.17:1 | 主按钮允许 |
| `#2563EB`／`#EFF6FF` | 4.75:1 | 选中允许，仍需勾选等第二信号 |
| `#0F172A`／白 | 17.85:1 | 标题、正文允许 |
| `#475569`／白 | 7.58:1 | 次级正文允许 |
| `#64748B`／白 | 4.76:1 | 辅助文字允许；换底色需重算 |
| `#15803D`／`#F0FDF4` | 4.79:1 | 成功标签允许 |
| `#B45309`／`#FFFBEB` | 4.84:1 | 警告标签允许 |

禁止：用红／绿差异作为唯一状态；低透明文字叠照片；绿底搭绿字；每个模块给主按钮换色；“没有记录”画成红色告警；不可访问动作伪装正常按钮。字段默认边界、聚焦、错误分别用control／focus／danger；只读有文字说明，禁用不靠变淡单独解释。

## 6. 骨架屏与加载反馈

**结论：**首次长加载按真实结构占位；即时本地查询和用户提交使用局部反馈。**依据：**当前读取的页面以转圈／进度条为主，未发现已有骨架组件；App为本地数据，不能对每次筛选强制闪烁。**范围：**看板、列表、详情、统计、附件。**执行：**以下时序是拟定产品标准，不是现有性能实测。

### 6.1 使用范围

| 页面／模块 | 首次无数据缓存时的占位结构 | 保持加载可交互的区域 |
|---|---|---|
| 首页概览 | 两组各2×2指标框，标签／数字／单位占位对应八项真实指标 | 顶栏、概览／处理切换、底导航 |
| 首页处理、人员／库存／采购看板 | 与各自最终布局对应的指标／入口和3行任务占位；不把概览八指标搬入处理 | 顶栏、底导航、静态入口 |
| 人员／车辆／采购／库存列表 | 4–6行；名称条宽55–70%、辅助条40–60%、状态短块 | 搜索／当前筛选状态；骨架本身不可点 |
| 人员／车辆／库存／采购详情 | 身份框+实际2–3个分区；保留操作条位置 | 返回；依赖数据的编辑按钮禁用并说明 |
| 日考勤／工资编辑 | 与实际姓名列、状态列、金额列对齐的5行 | 日期／组／月份；批量动作数据未就绪时不可用 |
| 月表／月汇总／价格比对 | 已知列结构占位6行，保留表头；未知统计只占绘图区 | 月份、筛选、图例；不绘制假趋势 |
| 车辆车况 | 固定车型图可直接显示；部件状态短条占位 | 返回／Tab；数据加载完之前不默认“正常” |
| 附件 | 实际网格列数的6个方框；文件名短条 | 返回／分类；上传使用独立进度 |
| 新增表单／设置静态入口 | 不用整页骨架；选择器异步选项局部加载 | 其余字段可填写 |
| 导入／备份／恢复／导出 | 不用骨架；已知进度显示真实百分比，未知显示阶段名 | 仅显示流程实际支持的取消／后台行为 |

### 6.2 时序与降级

1. 0–200ms：不展示骨架，保留页面结构；已有数据保持显示，说明刷新中。
2. 超过200ms且没有内容：显示骨架；优先避免反复闪烁，真实内容就绪或出错立即退出，不为凑动画时长延迟内容；保留顶栏与筛选。
3. 骨架区域包络与真实区域目标偏差≤8dp；列表条数不必精确，列数、关键图框和操作占位必须一致。不用百分比伪装真实业务值。
4. 动画：单次扫光1200ms，方向统一左→右；同屏共用一个节奏；减少动态效果时静态占位。禁止多个Widget各自创建循环控制器。
5. 5秒后同区域提示“加载时间较长”；10秒后出现“重新加载”且保留仍在运行的说明；实际操作未取消不能宣称失败。明确失败展示错误态，结束占位。长备份／导出按操作进度，不套查询超时规则。
6. 内容出现采用120ms淡入；不先显示0／“正常”再变真实值；不在失败后显示空态。
7. 低性能设备采用静态骨架，附件单张失败只替换该cell；Tab切换和筛选有缓存时保持旧内容并标明正在更新，结果不得与旧筛选语境混淆。

## 7. 拇指安全区

**结论：**主动作靠近底部且避开系统区域；危险动作移入确认层。**依据：**日考勤与出入库是频繁操作；顶部加号、紧凑器械按钮和FAB占位不一致。**范围：**所有移动端页面。**执行：**48×48dp最小点击区依据[Flutter官方建议](https://docs.flutter.dev/ui/accessibility/ui-design-and-styling)；下述拇指区域是本项目布局建议，不宣称所有用户手长相同。

| 区域／尺寸 | 标准 | 适用范围 |
|---|---|---|
| 底部主操作区 | 在系统bottom inset之上；左右16；上／下12；按钮高52；区域默认高76+bottomInset | 保存、确认入库、工资当前步骤 |
| 核心点击区 | 可用内容下方约40%作为首选频繁点击位置；有底导航时在其上方布局 | FAB、批量入口、上下步；保留左手可达的全宽按钮 |
| 最小点击区 | 48×48；主要提交52；图标可见24；相邻目标建议8dp间隔 | 所有可交互图标、cell、选择器、Tab |
| FAB避让 | 距内容左右／底16；有底导航时距导航上缘16；列表底padding≥FAB高度+32 | 列表新增；不得与行内主动作重叠 |
| 底部导航 | **4项：首页／考勤／汇总／我的**，等宽；可见高64+系统底部inset；图标24、标签12；命中≥48高 | 已确认目标；当前源码5分支是待迁移现状；选中统一主蓝 |
| 危险操作 | 默认放更多；确认层危险／取消按钮间至少16；布局窄时纵排全宽48 | 删除、覆盖恢复、撤销单据、盘点确认、工资锁定 |
| 系统避让 | SafeArea处理切口／导航手势；系统左、右回退边缘16dp内不放自定义滑动唯一入口 | 全部页，不能与Android回退竞争 |
| 键盘避让 | 输入页提交条可随键盘上移或随表单滚动；不得覆盖当前字段与错误；不能重复叠bottomInset和viewInsets | 长表单、弹层、采购明细 |

不得以`FittedBox`、低字号或compact density让点击区小于48。密集月考勤表只读格可40dp，**可编辑格必须≥48dp**，必要时点行进入半日编辑弹层；图上车况节点视觉可以小，但放大命中区且不得互相重叠，邻近节点提供列表入口。普通室内／室外与标准尺寸已确认，不启用全局56dp强化档；主提交52dp和最小点击48dp继续执行。

## 8. 字阶层级差

**结论：**全局一套字阶，密度差异主要靠布局而非局部缩字。**依据：**全局12sp辅助与器械11sp、库存部分10sp、购买默认TextTheme混用。**范围：**所有中文、数字、单位和按钮。**执行：**字号单位sp，表中行高为默认字号下逻辑px；中文默认letterSpacing=0。

| Token | 字号 | 字重 | 行高 | 字距 | 用法／Flutter建议映射 |
|---|---:|---:|---:|---:|---|
| `type.display` | 32 | 700 | 40（1.25） | 0 | 仅核心看板数值，可映射displaySmall；不用作页面大标题 |
| `type.metric` | 28 | 700 | 36（1.286） | 0 | 度量／总金额，headlineLarge |

| `type.modalTitle` | 20 | 600 | 28（1.4） | 0 | 弹层／对话框，titleLarge |
| `type.section` | 18 | 600 | 28（1.556） | 0 | 分区，titleMedium |
| `type.rowTitle` | 16 | 600 | 24（1.5） | 0 | 名称／对象，titleSmall |
| `type.body` | 16 | 400 | 24（1.5） | 0 | 正文／输入值，bodyLarge |

字体建议先用Android系统中文无衬线以降低实现复杂度；思源黑体／Noto Sans SC需字体授权、包体积和效果确认后自带。跟随系统`TextScaler`；1.0、1.3、2.0做适配样板。行高比例保持，按钮／列表增高；标题允许换行。不得全局截断字体缩放，不用缩小文字隐藏溢出。金额可分行显示单位，姓名可两行；完整值在详情可读。

## 9. 8 倍数间距系统

**结论：**以8dp建立布局节奏，4dp仅用于紧密关系；形状与描边不强制8倍数。**依据：**首页当前5／6dp、采购9／10／14／18／20dp、器械10dp等散值并存。**范围：**页面、模块、卡片、列表、按钮群与表格。**执行：**布局间距只从下表取值，例外记录理由。

| Token | dp | 用法 |
|---|---:|---|
| `space.0` | 0 | 无间距、边到边分割 |
| `space.micro` | 4 | 图标到短状态、label与补充字；仅组件内部 |
| `space.1` | 8 | 图标与文字、卡片之间、字段label到输入、按钮间 |
| `space.2` | 16 | 页面水平边距、卡片内边距、字段之间、列表分组 |
| `space.3` | 24 | 模块之间、标题组与内容、空态块内主要间隔 |
| `space.4` | 32 | 页面大型区块、首个空态与上下文的间距 |
| `space.5` | 40 | 插画与表单／正文独立区隔；不用于每张列表卡 |
| `space.6` | 48 | 大屏主要分区留白 |
| `space.8` | 64 | 大屏页面区隔，手机默认不用 |

| 布局部位 | 标准 |
|---|---|
| 手机页面 | 横16；顶8（顶栏后）；末尾24，叠加实际固定操作区占位 |
| 模块／卡片 | 模块间24；同组卡间8；卡内16；分组标题到首行8 |
| 表单 | 字段之间16；分区之间24；label到输入8；错误到输入4 |
| 列表 | 同卡行内上下12为**密度例外**，保证56/72/88总高度；独立卡间8 |
| 二列网格 | 间隔8或16；同页固定一种；左右页面边距16 |
| 表格 | cell水平12为**密度例外**；表头高48；只读行40–48；可点行／cell48起 |
| 固定操作栏 | 水平16；垂直12为**触达例外**；与正文分割1dp |
| 空态 | 图标→标题16；标题→说明8；说明→按钮24 |

明确例外：1／2dp描边、图标24、圆角6／8／12／16、系统inset、字形实际行高、Chip内垂直4与状态标签高24、行内12及操作栏12。它们属于不同尺度或可解释密度，不新增任意5／6／9／10／14／18／20间距。不可为了8倍数裁掉系统安全区。

## 10. 引导式空状态

**结论：**说明当前为什么空，以及从哪里开始；正常无待办保持安静。**依据：**库存已有“先新增物资”的前置引导，日志／工资历史／单位管理部分仅一行空文案，筛选空与首次空容易混用。**范围：**所有列表、详情、统计与依赖页面。**执行：**空状态必须来自已成功返回的数据，不从loading/error推导。

### 10.1 文案及结构

结构：业务图标48dp → 标题18/600（≤14个汉字）→ 原因／价值16sp（建议≤2行，长说明最多3行）→ 主行动48dp（动词+对象）→ 可选次级教育链接。主体宽≤320dp、水平24；正常字体总高目标≤240dp，大字允许增高。占内容区上半部或业务模块内部，不把主行动挤到屏幕边缘。空态不含假数据和不可执行按钮。

| 场景／真实触发 | 示例标题与说明 | 主行动／教育路径 | 适用页 |
|---|---|---|---|
| 首次无档案 | 尚未建立人员档案／“添加人员后，可维护考勤与工资资料。” | 新增人员 → 人员表单 | 名单、人员入口 |
| 前置条件不足 | 本月还没有考勤人员／“先将人员加入本月名单，再记录每日考勤。” | 管理月度名单 → 对应月份名单页 | 日考勤／月表 |
| 月份无记录 | 本月暂无请假记录／“登记请假后，将同步对应日期的考勤状态。” | 新增请假，携带当前月份上下文（若已有路由支持） | 请假／加班；文案按真实副作用改写 |
| 无物资档案 | 先建立物资档案／“入库、出库与盘点都需要关联物资。” | 新增物资 → 表单，保存后返回原任务（返回链建议项） | 入库／出库／盘点 |
| 暂无采购 | 尚无采购记录／“先登记需求，再跟踪申报、领取和入库。” | 新建采购 → 创建页 | 采购首页／历史 |
| 筛选无结果 | 未找到符合条件的记录／“试试更换关键词或清除筛选。” | 清除筛选；保留输入便于修改 | 所有搜索列表 |
| 正常无待办 | 当前没有待处理事项／“新的待办会显示在这里。” | 不设置强主按钮；可查看全部 | 首页待办／库存预警／采购任务 |
| 无统计样本 | 尚无可分析记录／“新增维修记录后，将生成费用与价格对比。” | 新增维修记录 | 器械分析／价格比对 |
| 无工资批次 | 本月尚未生成工资批次／“完成考勤与工资资料维护后，可开始核算。” | 开始造资；前置缺失则管理工资资料 | 工资首页 |
| 无附件 | 暂无附件资料／“可添加身份证、保险材料或票据。” | 添加附件；不同模块使用真实支持的类型 | 人员／车辆／维修附件 |
| 正常无历史 | 暂无操作记录／“执行新增、修改等操作后，可在这里查阅记录。” | 无强按钮，可返回工作台 | 操作日志 |
| 缺失／已删除对象 | 记录不存在或已删除／“返回列表查看其他记录。” | 返回对应列表 | 所有详情无效ID／缺失记录 |

### 10.2 插画与异常区别

默认使用统一Material outlined业务图标48dp，不用装饰性人物插画。首次使用以步骤与可执行入口引导；空待办、搜索无结果、错误、删除对象不使用庆祝插画。附件失效用文件占位+“文件不可用”，不能伪装正常空白。

错误态使用“任务 + 原因 + 恢复动作”：如“入库数量必须大于0，请修改数量”。采购超量入库是**允许确认后继续的警示**，提示“本次超过剩余数量X，确认超量入库？”并保留取消／仍然入库，不能设计为硬阻断。本地App不套用“检查网络”作为统一错误文案。系统权限缺失说明需哪项权限、用途和进入设置路径；取消文件选择不当作错误。权限是否需要、是否能打开设置按当前实现核验。

## 11. 页面适配与 Flutter 落地

### 11.1 画布与适配规则

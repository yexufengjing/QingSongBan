# 库存 UI 参考图差异排查

日期：2026-10-01  
参考基准：`UI设计与美术资源/05_库存管理UI/01_库存管理首页.png` 至 `08_库存流水.png`。八张图均已逐张打开检查；另外检查了 `docs/acceptance/ui-reference-audit/before-inventory.png` 的安卓首页基线，以及库存页面、路由、共享组件和相关表单源码。

## 视觉基准

参考图采用白色圆角内容卡片、浅灰蓝搜索/表头底、薄荷绿统计底、绿色主要操作、橙色预警、红色缺货或差异。列表按“标题与业务对象 → 关键数量/状态 → 次级字段”分层；统计卡通常三张一排；首页快捷入口为四列。已有 App 的浅色主题及 `InventorySection`、`InventoryStatusChip` 继续沿用，业务状态继续用文字和颜色共同表达。

没有物资图片字段，也没有参考图之外详情/表单的专用设计稿，所以列表使用库存图标作占位，详情与表单根据相邻参考页、现有 Material 3 控件及字段校验推导；不复制图中示例名称、数量或日期。

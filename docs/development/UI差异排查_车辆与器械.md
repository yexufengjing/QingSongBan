## 车辆无单独详情图页面及弹窗默认处理

下列页面没有独立参考图，按车辆档案、维修、车况和表单视觉层级推导；原有校验和数据流程不变：

| 页面文件 / 入口 | 默认处理和入口 |
| --- | --- |
| `vehicle_form_page.dart` / 首页或档案页“新增车辆”、档案卡编辑 | 车辆新增/编辑表单使用统一字段标签、输入框、必填校验与底部保存；文件上传未给定界面参考，走附件管理实际入口。 |
| `vehicle_detail_page.dart` 概览 tab / 车辆档案卡 | 档案卡 chevron 进入详情；顶部附件、编辑动作有明确 tooltip；“标记车辆停用”确认框由概览快捷操作进入，取消/确认分别关闭或写入停用状态。 |

# 车辆静态多视角方案

## 目标与素材

车况页改为固定视角图片。以 `assets/vehicles/sweeper-truck.png` 和 `assets/vehicles/water-truck.png` 为外形基准，使用两张 1254×1254 的透明四宫格图集：`sweeper-angles.png`、`water-angles.png`。每张图集约 1.2～1.3 MB，四个分区各为 627×627。

| 图集分区 | 视角 | 必须看到 |
| --- | --- | --- |
| 左上 | 右前方 `frontRight` | 车头、车辆右侧（驾驶员视角） |
| 右上 | 左前方 `frontLeft` | 车头、车辆左侧（驾驶员视角） |
| 左下 | 右后方 `rearRight` | 车尾、右侧 |
| 右下 | 左后方 `rearLeft` | 车尾、左侧 |

左右均以驾驶员坐在驾驶位面向车头时为准，不按画面左右命名。特别是左上象限车头朝画面右、可见车辆右侧，因此映射为 `frontRight`；右上象限映射为 `frontLeft`。切换视角时直接切换分区图像，每次按钮或水平滑动只移动一个视角；重置回左前方。显示时等比例裁切分区内部透明边距，不镜像、不拉伸，也不以车头图片冒充车尾。图集是依据单张原素材补全的视觉示意，未提供的背面细节不作为车辆实物检查依据。

## 节点与数据对应

每个视角单独配置节点，坐标以当前分区的宽、高归一化到 `0..1`。只显示该视角实际可见的部件；左右轮胎按驾驶员视角命名，绝不根据屏幕左右推断轮位。

| 节点 | 数据来源 | 无记录时 |
| --- | --- | --- |
| 外观/车身 | `VehicleConditionItem` 的 `exterior:exteriorMain` | 灰色，显示尚无检查记录 |
| 发动机 | `engine:engineMain` | 灰色，显示尚无检查记录 |
| 车灯 | `light:lighting`，只在能辨认灯具的视角出现 | 灰色，显示尚无检查记录 |
| 清扫系统 | 扫路车 `sweeper:sweeperMain` | 灰色，显示尚无检查记录 |
| 水路/喷头 | 洒水车 `water:waterMain` | 灰色，显示尚无检查记录 |
| 可见轮胎 | 当前 `TireInstallation.position` 及关联 `Tire` | 灰色，显示未安装或暂无轮胎资料 |

轮胎详情展示准确轮位、轮胎编号、磨损级别和安装情况。后轮内外侧轮胎如在当前图像中无法分别辨认，不叠加两个会混淆的热点，保留在下方六轮位清单查看。异常颜色仅来自实际记录；不存在的记录不默认为“正常”。部件节点点击后的名称、状态、备注与该节点的实际键一一对应。

## 验收

在扫路车和洒水车各检查四个视角：前视角确实看到车头，后视角确实看到车尾，左右侧细节方向正确；切换后节点跟随图像，不漂到其他部件；点选各节点核对数据来源。检查 320dp 与 411dp 宽度以及 Android 模拟器实际显示，确认图片不被裁切、节点可点、无布局溢出。更换图片不涉及数据库迁移。

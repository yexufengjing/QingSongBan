## 参考图不明确处与默认处理

1. 物资图片：现有库存无照片字段，统一使用库存占位图标；不扩展数据库或按图片生成虚构物资照片。
2. 样例姓名、年份、日期、数量、统计：由实际记录计算；演示数据明确标识，不能声称是生产数据。示意图各页状态颜色不完全一致：待申报列表标签绿、首页待申报指标橙；已申报卡蓝；采购中卡绿，首页采购指标蓝。
3. 保存草稿与保存待申报：现有模型无独立草稿状态，均保留现有待申报保存语义，不新增状态。
4. 入库位置：图有必填星号和选择箭头，但现有业务允许选填自由输入；保留现有契约，按数量→日期→位置→备注排列，不新增位置字典或必填限制。
5. 多物资、超量、历史补录、取消、空态和弹窗：图未完整覆盖，保留现有业务，使用相邻采购页颜色、白卡和控件。跨单位数量分别显示。
6. 系统状态栏、设备边框、底部全局导航及字体：按当前App路由与系统环境呈现；没有对应契约的按钮不编造业务。常规屏对齐结构，320窄屏/1.5字号允许换行以避免截断。

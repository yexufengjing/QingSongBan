# 第三方依赖与许可证

备忘提醒功能只通过公开包 API 复用成熟能力，没有复制 Tasks.org、Vikunja 或其他 GPL/AGPL 项目的源代码。

| 依赖 | 锁定版本 | 用途 | 许可证 | 使用边界 |
| --- | --- | --- | --- | --- |
| `rrule` | `0.2.18` | RFC 5545 重复规则解析与实例计算 | Apache-2.0 | 仅调用包 API，不复制内部实现 |
| `flutter_timezone` | `5.1.0` | 获取设备 IANA 时区 | Apache-2.0 | 仅调用包 API，不复制内部实现 |
| `flutter_local_notifications` | `19.5.0` | 本地通知调度、权限和通知操作 | BSD-3-Clause | 延续项目既有依赖，用统一 Scheduler 封装 |
| `timezone` | `0.10.1` | 时区数据和 `TZDateTime` | MIT | 延续项目既有依赖 |

`rrule` 和 `flutter_timezone` 的许可证文本随 Pub 缓存包提供；版本升级时需要重新核对许可证并同步本表。调研的 Super Productivity（MIT）、Tasks.org（GPL-3.0）和 Vikunja（AGPL-3.0）仅用于产品交互和领域建模参考，不作为运行时依赖。

# 安全发布与备份恢复

## Release 签名

Release 构建必须通过外部环境变量提供签名信息，缺少任一变量时构建会直接失败：

```text
QSB_RELEASE_STORE_FILE
QSB_RELEASE_STORE_PASSWORD
QSB_RELEASE_KEY_ALIAS
QSB_RELEASE_KEY_PASSWORD
```

keystore、密码和本机环境配置不得提交到 Git。Debug/Profile 构建继续使用项目现有配置。

发布前至少执行：

```powershell
D:\Flutter\bin\flutter.bat build apk --debug
D:\Flutter\bin\flutter.bat build apk --release
```

第二条命令必须在已注入上述四个变量的发布环境执行；本地无密钥时应看到明确的签名缺失错误。

## 备份恢复

新备份使用 v3 外层加密格式：随机 salt、随机 nonce、PBKDF2-HMAC-SHA256 和 AES-256-GCM。密码只在创建/恢复期间使用，不写入数据库或配置，最少 8 个字符。

恢复旧 v1/v2 备份时仍会校验 SQLite、manifest 和附件，但恢复前安全备份也必须使用一个新的至少 8 个字符密码。恢复会先在临时目录完成校验，再生成安全备份并原子替换数据库和附件；失败时回滚，成功后由 Android MethodChannel 触发安全重启。

Android 系统自动备份已关闭，身份证、工资、数据库和附件不会由系统备份策略自动复制。

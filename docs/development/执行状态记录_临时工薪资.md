4. 完成功能

- 工种、默认日薪、生效月份日薪历史和人员工资资料。
- 按月份生成临时工工资名单，去重多考勤组人员，支持人工添加、移除、恢复和排序继承。
- 统一工资计算：半天出勤换算天数，基础工资 + 补助 - 保险扣除，结果小于 0 时归零。
- 支持考勤同步、异常检查数量、异常项定位、确认、撤销确认、锁定、解锁、工资历史和人员工资记录。
- 已确认或已锁定批次保持只读；快照保证历史工资不受后续人员资料和日薪修改影响。
- 独立工资 Excel 导出，按 `displayOrder` 输出中文、半天出勤、两位小数、合计和固定文件名。
- 编辑器保存前实时预览基础工资和最终工资，草稿删除需要二次确认，工种设置展示日薪生效历史。
- 工资批次和工资设置关键变更写入 `operation_logs`，并同步按批次隔离的本地工资提醒。

# 临时工薪资功能执行状态记录

记录时间：2026-09-13（Asia/Shanghai）

## 当前结论

临时工薪资功能主体已按执行文档实现，数据库从 schema 8 升级到 schema 9。工资金额按元使用 SQLite `REAL` 保存，业务层统一保留两位小数；当基础工资、补助和保险扣除计算结果小于 0 时，最终工资记为 0.00，并保留异常警告。

schema 8 → 9 的真实文件迁移验证已完成：人员和旧考勤记录均可正常读取。当前工作区已通过完整分析、测试和 Android APK 构建验收。

- `lib/features/payroll/presentation/payroll_group_filter.dart`：工资首页和造资页的考勤组筛选组件。
- `test/payroll/`：工资计算、工资批次、排序继承、状态流转和 Excel 导出测试。
- `docs/development/执行状态记录_临时工薪资.md`：本次实施记录。

2. 修改文件

- 数据库表、枚举、迁移和生成代码。
- 应用路由、首页、报表、设置、人员详情及提醒类型。
- 临时工薪资执行文档和当前数据库 Schema 文档。

3. 数据库变化

- schemaVersion：8 → 9。
- migration：新增 `wage_job_types`、`wage_rate_history`、`employee_wage_profiles`、`payroll_batches`、`payroll_items`、`payroll_adjustments` 六张表。
- 原人员、考勤、保险和操作日志表保持不变。

4. 完成功能

- 工种、默认日薪、生效月份日薪历史和人员工资资料。
- 按月份生成临时工工资名单，去重多考勤组人员，支持人工添加、移除、恢复和排序继承。
- 统一工资计算：半天出勤换算天数，基础工资 + 补助 - 保险扣除，结果小于 0 时归零。
- 支持考勤同步、异常检查数量、异常项定位、确认、撤销确认、锁定、解锁、工资历史和人员工资记录。
- 已确认或已锁定批次保持只读；快照保证历史工资不受后续人员资料和日薪修改影响。
- 独立工资 Excel 导出，按 `displayOrder` 输出中文、半天出勤、两位小数、合计和固定文件名。
- Android 导出的工资表和月度报表写入系统 `Download`（下载）目录，便于通过文件管理器直接查找；非 Android 平台保留应用 `exports` 目录。
- 编辑器保存前实时预览基础工资和最终工资，草稿删除需要二次确认，工种设置展示日薪生效历史。
- 工资批次和工资设置关键变更写入 `operation_logs`，并同步按批次隔离的本地工资提醒。
- 手动加入零出勤人员时增加二次确认；工资明细进入月考勤时保留工资批次月份；锁定工资保留确认时间。
- 工资首页和造资页支持按当月考勤组筛选，筛选不改变工资批次名单、排序和汇总金额；工资明细显示参保状态。
- 停用工种提供“启用工种”入口；修改工种与添加生效日薪使用统一表单布局，生效月份支持年份和月份选择。
- 工资批次考勤快照改为只比较实际考勤业务数据，汇总确认、重新生成记录时不会再被误判为考勤变化；确认/解锁输入弹窗改为安全的无控制器输入，避免键盘收起时的生命周期异常。

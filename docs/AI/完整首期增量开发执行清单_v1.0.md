## 2. 接口变化

| 接口/模块 | 本阶段增量 |
|---|---|
| 意图与页面上下文 | 支持考勤、单车年度维修、年度排名三类任务；页面上下文增加本地vehicleId/year；保留现有考勤调用兼容，模型不接收ID、姓名、车牌或候选清单 |
| 会话与调度 | 记录当前业务类型及已校验对象/日期；显式输入与新车辆页面“问助手”的对象选择优先，其次本轮、页面、当前年。切换类型清除不适用对象/月，不能把考勤月份静默转换为车辆条件。“全部车辆”清除单车限制；重复“去年”始终为设备上一年 |
| 车辆只读端口 | 本地车辆精确解析/候选选择、年度单车快照、全车完整聚合排名；删除对象/失效引用受控拒绝；刷新重读数据 |
| 车辆结果 | 单车：车辆本地标签、年份、completedRepairCount、actualAmountCents、currency、口径/查询时间、本地明细与来源；排名：总数、已返回数、并列名次、分页状态/会话绑定引用；点击排名项直接读取同年份单车并保留排名 |
| Provider与投影 | 只扩展允许的意图schema/提示及白名单投影，不开放任意SQL/路由/方法。单车外发仅year/count/amount/currency；排名只发必要匿名alias/rank/count/amount及覆盖信息，不发真实身份/备注/明细 |
| UI状态 | 会话级草稿与浮窗状态保存在运行内存；浮窗/独立页复用同一聊天内容。导航由本地已校验结果构造，不执行模型给出的地址 |

新增类型和事件的最终名称由核心代理先固定并通知界面代理，写入验收记录；不为名称统一重写已验收接口。

车辆口径固定为：未删除车辆；未删除且已完成维修单；按reportDate自然年筛选；actualAmountCents整数分求和。展示日期可为completedAt ?? reportDate。单数不等于原页面全部报修次数，不混入油耗/保养/其他费用或再叠加备件。无单与有零金额单分别表示。

全车排名先对完整未删除车辆集合聚合（含停用车辆），再按金额降序排名，金额相同采用1、1、3；同金额以本地车辆编号/ID稳定排序。每页默认10条，总数和分页可见；全部无记录时不宣称“最高费用车辆”。分页引用绑定会话/结果；刷新或清空后拒绝旧引用。

## 3. 悬浮生命周期

| 状态/动作 | 行为 |
|---|---|
| 隐藏/入口 | 首页全局入口及现有设置入口可打开；页面“问助手”传明确上下文。隐藏不清会话，不新增底部Tab |
| 收起 | App内可拖动入口，提供靠左/靠右替代动作，位置约束在安全区；不遮挡底部导航/主要保存动作 |
| 展开 | 复用聊天、输入、结果；可收起/关闭/转独立页。小屏或键盘压缩到不可用时转全屏，保留草稿 |
| 独立助手页 | 不显示第二个悬浮入口；返回恢复原来的单一入口和会话，不重新发请求 |
| 查询中 | 可停止、收起；收起不重新请求，跨页面不改变当前任务对象；页面上下文用于后续查询，在页面有效期间可重复使用，离开/换对象才更新或清除；提交时捕获快照 |
| 返回/业务弹窗 | 返回优先关闭局部选择，再收起展开助手，再交原页面；原业务弹窗/选择器和系统文件流程优先，助手暂时收起/隐藏，不截获结果 |
| 来源导航 | 展开助手暂时隐藏，原费用/维修页面直接可见；返回恢复会话与草稿，不重新请求。浮窗和转全屏后均适用 |
| App后台 | App外不显示、不申请系统悬浮窗权限/前台服务；后台不新发请求，取消在途请求并使迟到响应无效；回来保留已有结果，不自动重试 |
| 重启/旋转 | 重启会话不持久恢复，Key仍保留；旋转、键盘和窗口尺寸变化重约束位置，输入与主要动作可见 |

全局挂载位于MaterialApp路由层之上，覆盖shell内外页面；不只挂AppShell。涉及app.dart/路由观察的必要改动限悬浮与上下文，不改原业务导航语义。

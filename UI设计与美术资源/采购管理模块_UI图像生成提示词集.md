# 采购管理模块 UI 图像生成提示词集

> 适用项目：轻松办  
> 模块：采购管理  
> 用途：用于基于统一视觉规范生成采购管理模块各功能页面 UI 设计预览图  
> 组织方式：统一风格母 Prompt + 各页面子 Prompt  
> 建议：每次生成页面时，将“统一风格母 Prompt”与对应页面“子 Prompt”一起使用，以保证整套页面风格统一。

---

# 一、统一风格母 Prompt

```text
为中国企业内部个人工作管理 App“轻松办”设计一套手机端高保真 UI 界面，整体视觉必须严格保持统一，适用于采购管理模块。

【产品定位】
“轻松办”是一款面向个人日常工作管理的移动端工具，用于记录人员、考勤、库存、车辆、提醒、采购等事务。
采购管理模块不是企业 ERP，也不替代公司 OA，不负责真正执行采购，而是用于记录用户本人向企业 OA 申报采购后的进度跟踪，以及物资领取后进入本人管理小仓库的全过程。

【设备与画面】
移动端 App UI，高保真界面设计稿，竖屏 9:19.5 比例。
完整展示单一手机页面，不显示手机外壳，不做展示海报，不做 PC 后台，不做网页后台。
界面应真实可落地开发，像成熟 Figma 产品稿。

【整体风格】
Clean Minimal + Soft & Friendly。
现代国产企业数字化办公 App 风格，兼具政企数字化平台与轻量办公工具气质。
界面清爽、专业、可靠、稳定、克制，不做复杂 ERP 风格，不做炫技视觉。
使用大面积浅灰蓝背景 + 白色圆角卡片 + 极轻阴影 + 清晰层级 + 充足留白。
卡片圆角约 12–16px，按钮圆角 10–12px。
采用 8pt spacing grid，模块间距统一，整体节奏整齐。

【品牌配色】
品牌绿色：#00C16B
辅助科技蓝：#1677FF
标题深蓝：#0F2746
正文灰蓝：#5B6B7B
辅助灰：#94A3B8
浅绿背景：#E8F8EF
浅蓝背景：#E8F1FF
浅橙背景：#FFF3E4
浅红背景：#FDECEC
页面背景：#F6F9FC
分割线：#E5EAF0
卡片背景：#FFFFFF

绿色用于主操作、已完成、库存入库；
蓝色用于 OA 信息、流程、辅助操作；
蓝绿色用于“采购中”；
橙色只用于待处理、待领取、提醒；
红色仅用于取消、异常，不大面积使用。

【字体规范】
中文使用“思源黑体 / Source Han Sans SC”或系统无衬线字体。
H1 页面标题：22–24px Semibold / Bold
H2 区域标题：18px Semibold
H3 卡片主标题：17–18px Semibold
正文：14–16px Regular
辅助说明：12–14px Regular
数字可适度使用 Semibold。
文字清晰、现代、克制，不使用艺术字、书法字体、衬线字体。

【顶部导航】
统一使用白色顶部导航栏：
左侧返回箭头；
标题采用深蓝色粗体；
右侧可使用搜索、更多、保存等小型操作。
导航栏简洁，不使用大面积渐变。

【卡片组件】
统一白色圆角卡片；
卡片边缘使用极轻阴影或 1px 浅灰描边；
卡片内部信息上下分层清晰；
不要把所有字段做成密集表格。

【按钮规范】
主按钮：#00C16B 绿色背景 + 白字
辅助按钮：#1677FF 蓝色
次级按钮：浅绿 / 浅蓝背景
描边按钮：白底 + #E5EAF0 边框
文字按钮：绿色或深蓝
禁用按钮：浅灰绿色
按钮高度约 44–48px，适合手机触控。

【输入框规范】
白色或极浅灰背景；
1px 浅灰蓝边框；
圆角 10–12px；
Focus 使用品牌绿色描边；
Placeholder 使用 #94A3B8；
下拉、日期、人员选择使用统一小图标。

【标签 / Chips】
使用小型圆角胶囊标签：
待申报：灰蓝 / 浅绿
已申报：科技蓝
采购中：蓝绿色
待领取：橙色
已入库：品牌绿色
已取消：浅灰红
背景为状态色的 10%–15% 浅色版本，文字使用对应深色。

【图标风格】
统一 Soft Rounded / Flat Color / 简洁线性图标。
线条圆润、现代、轻量。
采购相关图标可使用：
文件清单、OA 流程、人员、时间、仓库、纸箱、库存、铃铛、日历、入库箭头、历史记录。
避免复杂拟物、3D 强质感、像素风。

【空状态与插画】
如需要空状态插画，使用轻量扁平矢量插画：
浅蓝城市或仓库背景、绿色箱体、文件清单、城市管理工作人员。
插画面积适中，不抢占主要操作区域。

【业务视觉优先级】
第一优先：待领取、当前需要用户处理的事项
第二优先：采购中的事项
第三优先：待申报 / 已申报
第四优先：已完成历史
通过状态标签、轻量图标、排序强化，不使用强烈警告视觉。

【统一底部导航】
如页面需要展示底部 Tab Bar，统一为：
首页、人员、考勤、汇总、我的
白色背景、极浅分割线、圆角线性图标。
当前入口使用品牌绿色高亮，其余使用灰蓝色。

【明确业务边界】
本采购管理模块仅记录：
物资名称
规格型号
单位
申报数量
当前库存
OA 申报时间
OA 流程编号 / 标题 / 链接
采购分部
采购执行人
分配时间
采购状态
待领取状态
领取地点
领取提醒
实际入库数量
入库日期
库存联动
采购历史
采购周期

界面中绝对不要出现：
采购金额
采购单价
采购总价
供应商
询价
比价
发票
付款
采购合同
采购验收
物流快递
电商购物
订单支付
财务分析

【整体关键词】
modern Chinese enterprise mobile app UI,
clean minimal,
soft friendly,
professional,
light blue-gray background,
botanical green,
technology blue,
white rounded cards,
subtle shadow,
high fidelity,
Figma quality,
Chinese OA work management,
clear hierarchy,
8pt grid,
production-ready,
simple and stable,
mobile procurement tracking,
inventory workflow,
consistent design system
```

# 十二、使用建议

每次生成某一个页面时，推荐按照以下方式组合：

```text
统一风格母 Prompt
+
对应页面子 Prompt
+
统一负面 Prompt
```

例如生成“采购跟踪”页面：

```text
[统一风格母 Prompt]
+
[页面 04：采购跟踪]
+
[统一负面 Prompt]
```

这样更有利于保持以下内容一致：

- 配色
- 字体
- 圆角
- 卡片结构
- 图标语言
- 按钮规范
- 状态标签
- 信息密度
- 页面层级
- 整体品牌感

建议整套页面生成时始终固定：
- 同一竖屏比例
- 同一品牌配色
- 同一图标风格
- 同一字号层级
- 同一底部导航
- 同一圆角和间距体系

最终目标是让 9 个采购页面看起来属于同一款真实、成熟、可开发的“轻松办”App，而不是 9 张独立风格的概念图。
